# 像素爱心卡片 💗 Pixel Love Card

一张像素风的互动小卡片：把"约TA出去"这件事，变成一场小小的冒险。

## 玩法流程

1. **约会邀请** —— "你愿意跟我出去吗？" YES / No（No 按钮会逃跑，还会撒娇拒绝你的拒绝 😤）
2. **庆祝答应** —— 耶！撒花！🎉
3. **选择活动** —— 看电影 / 吃火锅 / 看日落 / 逛一整天街，选定即锁定 🔒
4. **挑选日期** —— 内置像素日历，翻月选一天
5. **情书结尾** —— 打开 `情书.txt`，逐字打出一封小情书 💌

## 技术说明

- 单文件 `index.html`（HTML + CSS + 原生 JS），无任何依赖、无构建步骤
- 像素画使用 CSS `box-shadow` 逐像素绘制
- 8-bit 音效使用 Web Audio API 合成方波
- 打字机效果、粒子撒花、漂浮爱心均为纯 CSS/JS 动画
- 中文字体优先使用像素字体，加载失败时优雅回退到系统字体

## 本地预览

直接用浏览器打开 `index.html` 即可，或：

```bash
python -m http.server 8080
# 访问 http://localhost:8080
```
